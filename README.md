# StockScope A股实时分析（Windows 首版）

StockScope 是一个面向单只 A 股的桌面分析工具。默认股票为 **航天电器（002025）**，同时展示核心指数和行业/概念板块强弱。

## 首次运行

1. Windows 10/11 安装 [Python 3.11 或 3.12](https://www.python.org/downloads/windows/)，安装时勾选 **Add Python to PATH**。
2. 解压整个项目文件夹。
3. 双击 `start_windows.bat`。首次启动会建立独立环境并安装图表组件，之后直接启动即可。

如果希望在本机得到单独的 EXE，双击 `build_windows_exe.bat`。完成后文件位于：

`dist\StockScope-Windows.zip`

项目也带有 GitHub Actions Windows 构建流程，可自动生成
`StockScope-Setup.exe` 安装程序。安装程序采用当前用户安装方式，默认不要求管理员权限，
并支持开始菜单、可选桌面快捷方式和正常卸载。

## 已实现功能

- 输入任意 6 位 A 股代码，实时切换分析标的。
- 实时价格、涨跌幅、今开/最高/最低/昨收、成交额、换手率、PE/PB 和行业。
- 分时价格、分时均价、成交量，以及近 80 日 K 线和 MA5/MA10/MA20。
- “止跌确认仪”：低点是否下移、是否收回分时均价、短均线是否拐头、是否脱离日内低点、是否站上 5 日线、量价配合、RSI 状态。
- 自动计算确认参考价、信号失效参考、第一压力位和试仓上限。
- 上证、深证、创业板、沪深300，以及行业/概念板块强弱排行。
- 免费行情断开时保留界面，并明确显示“演示数据”或“降级”，不会把模拟数据冒充实时行情。

## 更新频率与数据说明

- 价格与分时约每 12 秒更新一次；日线、大盘和板块约每 90 秒更新一次。
- 使用无需账户的东方财富公开行情接口。免费接口没有稳定性或时效性保证，可能发生延迟、限流、字段变化或中断。
- 行情和交易价格必须以同花顺/兴业证券终端为准。
- 软件不会登录证券账户、不会读取交易密码，也不会自动下单。

## “止跌确认仪”怎么看

- **75–100**：止跌信号较强，但仍只给出轻仓试错参考。
- **58–74**：初步企稳，需要继续观察。
- **40–57**：确认不足，不宜因为“跌得多”就抢反弹。
- **0–39**：弱势风险较高。

“确认价”不是保证成交后上涨的买点；“失效参考”也不等于适合所有人的固定止损。实际使用时仍需结合账户总资金、持仓成本和单笔最大亏损。

## 项目结构

- `app.py`：程序入口
- `src/data_provider.py`：行情适配、降级和演示数据
- `src/analyzer.py`：技术指标、止跌评分和市场评分
- `src/ui.py`：Windows 桌面界面与图表
- `tests/test_core.py`：核心逻辑测试
- `config.json`：默认股票代码

## 运行测试

在项目目录打开命令提示符：

```bat
py -3 -m unittest discover -s tests -v
```
